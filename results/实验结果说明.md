# SRNet 实验结果说明

本目录保存本次 **BOSSbase＋BOWS2、S-UNIWARD 0.4 bpp** 复现实验的环境记录、训练与验证历史、独立测试结果和报告图像。以下路径均相对于本说明文件所在的 `results/` 目录。数据集和模型检查点分别交付，不包含在本结果目录中。

## 核心结论

- 训练：14,000 对训练图像，500,000 步；从 BOSSbase 留出 1,000 对验证图像，按最后 100,000 步内的最高验证准确率选择 **第 425,000 步**检查点。
- 独立测试：BOSSbase 留出的 **5,000 对**封面／隐写图像，与训练和验证编号互不重叠。
- 最小检测错误率：**`Pₑ = 0.0950`（9.50%）**；ROC AUC：**`0.97311562`**。题目要求 `Pₑ ≤ 0.18184`，本次结果达标。
- 论文式最小 Pₑ 对应的测试混淆矩阵为 `[[4450, 550], [400, 4600]]`，行是真实类别 `[封面, 隐写]`，列是预测类别 `[封面, 隐写]`。

最小 `Pₑ` 按等先验计算：`Pₑ = 0.5 × (误报率 + 漏报率)`。上述矩阵对应误报率 `550/5000 = 11.00%`、漏报率 `400/5000 = 8.00%`。此阈值取自**测试 ROC**，用于与论文的最小错误率口径一致；模型权重和检查点选择未使用测试图像。若改用验证集预先确定的阈值，测试混淆矩阵为 `[[4628, 372], [631, 4369]]`，`Pₑ = 10.03%`。

题目给出的 18.184% 是验收门槛；原论文表 II 中 S-UNIWARD 训练／S-UNIWARD 测试、0.4 bpp 对应数值是 10.23%。报告应区分两者。本项目使用固定的独立随机划分和 PyTorch/BF16 实现，不宣称与论文逐图、逐位相同。

## 文件索引

| 文件 | 内容与报告用途 |
| --- | --- |
| [evaluation.json](evaluation.json) | 最终检查点步数、测试 Pₑ、AUC、两种阈值及其混淆矩阵、验收判断；最终数值以此文件为准。 |
| [test_scores.csv](test_scores.csv) | **10,000 条**逐图测试分数：图像编号、`label`（0＝封面，1＝隐写）、隐写概率和检查点步数；用于重绘测试 ROC。 |
| [run_config.json](run_config.json) | 划分种子、数据量、批量、学习率边界、精度、GPU、PyTorch/CUDA 版本及关键源码哈希；用于说明实验条件。 |
| [train_history.csv](train_history.csv) | **5,000 条**训练记录，每 100 步记录一次近期均值：交叉熵、L2、总损失、准确率、学习率、速度和显存峰值；用于训练曲线。 |
| [validation_history.csv](validation_history.csv) | **100 条**验证记录，每 5,000 步记录一次：损失、准确率、Pₑ、AUC、误报率、漏报率、混淆计数和是否选为最佳检查点；用于选模与验证曲线。 |
| [visualization_manifest.json](visualization_manifest.json) | 新增图像的来源、示例图编号、测试指标核对值与文件路径。 |
| [tensorboard/](tensorboard) | TensorBoard 标量事件，便于交互查看完整训练和验证过程。 |
| [archived_fp32_step500/](archived_fp32_step500) | 仅 500 步的早期 FP32 试跑，**不计入本次 BF16 正式训练的结果或曲线**。 |
